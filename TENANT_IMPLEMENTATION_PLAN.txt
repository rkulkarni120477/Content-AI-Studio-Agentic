================================================================================
  CONTENT AI STUDIO — TENANT SYSTEM IMPLEMENTATION PLAN
================================================================================

GOAL
  Add full multi-tenancy to Content AI Studio so each organization (tenant)
  gets its own isolated workspace: separate users, projects, styles, documents,
  prompts, generations, and analytics. A platform admin (super-admin level) can
  manage all tenants from a central dashboard.

CURRENT STATE (what CAS has today)
  - JWT auth: Bearer token, payload has {sub, role, exp, iat}
  - Roles: admin / reviewer / author (no tenant concept)
  - User.username is globally unique — no isolation
  - No tenant_id on ANY table
  - Single-instance app — all users share all data
  - FastAPI backend (app/) + Streamlit legacy (promptops_app/) sharing the same DB
  - Alembic handles migrations (alembic.ini, migrations/)

TARGET STATE (after this implementation)
  - Login requires: tenant_slug (org code) + username + password
  - JWT payload: {sub, role, tenant_id, tenant_slug, is_platform_admin, exp, iat}
  - Every data table has tenant_id FK; queries automatically scoped
  - Platform admin (tenant_id=NULL, is_platform_admin=TRUE) manages all tenants
  - Existing data migrated into a default "default-org" tenant
  - Frontend login page gets org code input field
  - Platform admin dashboard at /platform/tenants

================================================================================
  PHASE OVERVIEW
================================================================================

  Phase 1 — Database models & Alembic migration
  Phase 2 — Auth layer (JWT + login endpoint)
  Phase 3 — Tenant scoping utilities
  Phase 4 — Repository / query updates
  Phase 5 — API route updates + new platform admin routes
  Phase 6 — Schemas (Pydantic)
  Phase 7 — Frontend (React/Redux)
  Phase 8 — Seed & migration script for existing data
  Phase 9 — Streamlit compatibility shim (keep legacy app working)

Do all phases in order. Each phase is independently testable before moving on.

────────────────────────────────────────────────────────────────────────────────
  3A. Content of app/core/tenant_context.py
────────────────────────────────────────────────────────────────────────────────

  from __future__ import annotations
  from sqlalchemy.orm import Query


  def apply_tenant_filter(q: Query, model, tenant_id: str | None,
                          is_platform_admin: bool = False) -> Query:
      """Scope a SQLAlchemy query to a tenant.

      Rules:
        - Platform admin with no tenant_id → returns all rows (unscoped)
        - Platform admin with tenant_id → filters to that tenant
        - Regular user → always filters to their tenant_id
        - If the model has no tenant_id column → returns query unchanged
      """
      if not hasattr(model, 'tenant_id'):
          return q
      if is_platform_admin and not tenant_id:
          return q   # platform admin sees everything
      if tenant_id:
          return q.filter(model.tenant_id == tenant_id)
      return q


  def get_scoped_or_404(db, model, pk: int | str,
                        tenant_id: str | None,
                        is_platform_admin: bool = False):
      """Fetch one row scoped to tenant; raises 404 if not found or cross-tenant."""
      from app.core.exceptions import NotFoundError
      q = db.query(model)
      q = apply_tenant_filter(q, model, tenant_id, is_platform_admin)
      obj = q.filter(model.id == pk).first()
      if obj is None:
          raise NotFoundError(model.__tablename__, pk)
      return obj


  def tenant_id_from_user(current_user) -> str | None:
      """Extract tenant_id from an authenticated user object."""
      return getattr(current_user, '_tenant_id', None)


  def is_platform_admin_user(current_user) -> bool:
      """Return True if the current user is a platform admin."""
      return bool(getattr(current_user, '_is_platform_admin', False))


  def effective_tenant_id_for_write(current_user, body_tenant_id: str | None = None) -> str:
      """Return the tenant_id to use for a CREATE/UPDATE operation.

      Platform admin:  reads tenant_id from the request body (required)
      Regular user:    always uses their own tenant_id
      Raises 400 if platform admin does not provide tenant_id.
      """
      from fastapi import HTTPException
      if is_platform_admin_user(current_user):
          if not body_tenant_id:
              raise HTTPException(
                  status_code=400,
                  detail="tenant_id is required for platform admin operations"
              )
          return body_tenant_id
      tid = tenant_id_from_user(current_user)
      if not tid:
          raise HTTPException(status_code=403, detail="Tenant context required")
      return tid

    def create_tenant(body, db, current_user):
        _require_platform_admin(current_user)
        import uuid
        # Validate slug (lowercase, no "platform", unique)
        slug = body.slug.strip().lower()
        if slug == "platform":
            raise HTTPException(400, "Reserved organization code")
        if db.query(Tenant).filter(Tenant.slug == slug).first():
            raise HTTPException(409, "Organization code already exists")
        tenant = Tenant(
            id=str(uuid.uuid4()), slug=slug, name=body.name,
            max_users=body.max_users, status="active",
            created_by=current_user.username
        )
        db.add(tenant); db.flush()
        admin = User(
            username=body.admin_username,
            password_hash=hash_password(body.admin_password),
            role="admin",
            tenant_id=tenant.id,
            is_active=True,
            is_platform_admin=False,
        )
        db.add(admin); db.commit()
        return _tenant_dict(tenant, db)

  PUT  /api/v1/platform/tenants/{tenant_id}
    Update name, max_users, status (active/suspended).
    Body: {name?, max_users?, status?}

    def update_tenant(tenant_id, body, db, current_user):
        _require_platform_admin(current_user)
        tenant = db.get(Tenant, tenant_id)
        if not tenant: raise HTTPException(404)
        if body.name:      tenant.name = body.name
        if body.max_users: tenant.max_users = body.max_users
        if body.status in ("active", "suspended"): tenant.status = body.status
        db.commit()
        return _tenant_dict(tenant, db)

────────────────────────────────────────────────────────────────────────────────
  8A. Content of scripts/migrate_to_tenant.py
────────────────────────────────────────────────────────────────────────────────

  import uuid
  from promptops_app.database import (
      SessionLocal, Tenant, User, Project, Style, Document,
      Prompt, CentralRepository, GenerationJob, LLMUsageLog, AuditLog,
      hash_password
  )

  DEFAULT_TENANT_SLUG = "default-org"
  DEFAULT_TENANT_NAME = "Default Organization"
  PLATFORM_ADMIN_USERNAME = "platformadmin"
  PLATFORM_ADMIN_PASSWORD = "ChangeMe123!"   # Must be changed immediately after run

  def run():
      with SessionLocal() as db:
          # 1. Create default tenant (idempotent)
          tenant = db.query(Tenant).filter(Tenant.slug == DEFAULT_TENANT_SLUG).first()
          if not tenant:
              tenant = Tenant(
                  id=str(uuid.uuid4()),
                  slug=DEFAULT_TENANT_SLUG,
                  name=DEFAULT_TENANT_NAME,
                  max_users=1000,
                  status="active",
                  created_by="migration",
              )
              db.add(tenant)
              db.flush()
              print(f"Created tenant: {DEFAULT_TENANT_SLUG} (id={tenant.id})")

          tid = tenant.id

          # 2. Assign existing users to the default tenant
          users = db.query(User).filter(User.tenant_id.is_(None)).all()
          for user in users:
              user.tenant_id = tid
              user.is_platform_admin = False
          db.flush()
          print(f"Migrated {len(users)} users to tenant '{DEFAULT_TENANT_SLUG}'")

          # 3. Assign existing projects to default tenant
          projects = db.query(Project).filter(Project.tenant_id.is_(None)).all()
          for p in projects:
              p.tenant_id = tid
          db.flush()
          print(f"Migrated {len(projects)} projects")

          # 4. Assign existing styles to default tenant
          styles = db.query(Style).filter(Style.tenant_id.is_(None)).all()
          for s in styles:
              s.tenant_id = tid
          db.flush()
          print(f"Migrated {len(styles)} styles")

          # 5. Assign existing documents to default tenant
          documents = db.query(Document).filter(Document.tenant_id.is_(None)).all()
          for d in documents:
              d.tenant_id = tid
          db.flush()
          print(f"Migrated {len(documents)} documents")

          # 6. Assign existing prompts (CAS prompt assets) to default tenant
          prompts = db.query(Prompt).filter(Prompt.tenant_id.is_(None)).all()
          for p in prompts:
              p.tenant_id = tid
          db.flush()
          print(f"Migrated {len(prompts)} prompts")

          # 7. Assign central repositories to default tenant
          repos = db.query(CentralRepository).filter(CentralRepository.tenant_id.is_(None)).all()
          for r in repos:
              r.tenant_id = tid
          db.flush()

          # 8. Assign generation jobs to default tenant
          jobs = db.query(GenerationJob).filter(GenerationJob.tenant_id.is_(None)).all()
          for j in jobs:
              j.tenant_id = tid
          db.flush()

          # 9. Assign audit logs to default tenant
          logs = db.query(AuditLog).filter(AuditLog.tenant_id.is_(None)).all()
          for l in logs:
              l.tenant_id = tid
          db.flush()

          # 10. Create platform admin user (idempotent)
          existing_admin = db.query(User).filter(
              User.username == PLATFORM_ADMIN_USERNAME,
              User.is_platform_admin == True
          ).first()
          if not existing_admin:
              platform_admin = User(
                  username=PLATFORM_ADMIN_USERNAME,
                  password_hash=hash_password(PLATFORM_ADMIN_PASSWORD),
                  role="admin",
                  tenant_id=None,
                  is_platform_admin=True,
                  is_active=True,
              )
              db.add(platform_admin)
              print(f"Created platform admin: {PLATFORM_ADMIN_USERNAME}")
              print(f"  IMPORTANT: Change password immediately after migration!")

          db.commit()
          print("Migration complete.")

  if __name__ == "__main__":
      run()

================================================================================
  KEY DESIGN DECISIONS
================================================================================

  1. NULLABLE tenant_id on all tables (not FK + NOT NULL)
     Reason: Existing data gets tenant_id=NULL until migration runs. This prevents
     startup crashes if migration and schema change don't happen atomically.
     After migration, app-layer code enforces it's always set on new records.

  2. JWT carries tenant_id (not fetched from DB per request)
     Reason: Keeps auth stateless — no extra DB lookup to know the tenant.
     Tradeoff: If a user is moved between tenants, they need to re-login.
     This is acceptable behavior for an enterprise app.

  3. Platform admin uses slug "platform" (reserved word)
     Reason: Mirrors what prompt-library does and is already familiar.
     The Tenant.slug validation must reject "platform" at creation time.

  4. Existing data migrates to "default-org" tenant
     Reason: Zero-downtime approach. The existing admin/author/reviewer users
     and all their data move to one default tenant. The platform admin is a
     separate new account (not an existing user promoted).

  5. apply_tenant_filter() is the single enforcement point
     Reason: Every query goes through this function, which means the scoping
     logic is in one place and easy to audit. Routes don't do raw filter() calls.

  6. Platform admin routes blocked from API key auth
     Not applicable here (CAS doesn't have API keys yet), but the platform
     admin endpoints should require Bearer JWT with is_platform_admin=True.

  7. Streamlit kept as a legacy parallel path
     Reason: Don't break the existing Streamlit app during migration.
     The Streamlit session just needs tenant_id stored in session_state and
     passed to the (now tenant-aware) DB query functions.
