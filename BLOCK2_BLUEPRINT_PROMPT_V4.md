conflicts explicitly rather than resolving them silently. No outside
or general knowledge — if it isn't in the supplied source material,
it doesn't go in the Blueprint.

  5. Specificity check — a spot-check that cells use literal

knowledge-test-style. Build Quick Check and quiz items around

WORKSHEET 4 FORMAT — REQUIRED

| Day | Day Title | Handbook Reference | ACS Code(s) | Concept Type | Concept Scope | Concept Type Explanation | Learn-While-Doing | Content Summary | Formative Assessment | Projects/Activities | Source Completeness | Flags |

"REVIEW NEEDED — no source available".

CELL DETAIL:
  - Day: plain integer (1, 2, 3 …), sequential — never a range, never text.
  - Day Title: the day's topic exactly as given in the course calendar.
  - Handbook Reference: the exact handbook and page/section cited for
    that day (e.g. "FAA-H-8083-31B, Ch. 4"), not just "the handbook" —
    "REVIEW NEEDED — no source available" only when the source truly
    names none for that day.
  - ACS Code(s): list every code active that day, verbatim, comma-separated.
    "REVIEW NEEDED — no source available" only when the calendar names

    (Interpret → Select → Perform → Protect) — state which stage(s)

    (Interpret/Select stage) from the learner actually DOING it
    (Perform/Protect stage) — a day describing a process in prose

    if the topic itself is a hands-on skill elsewhere in the block.
  - Concept Scope: the specific sub-topics, tools, or materials covered
    that day within the Concept Type stage (e.g. "Interpreting title

    "Drawings") — grounded in that day's actual source content, never a
    restatement of the Day Title.

    choice in what THIS day's sources actually contain — never a
    generic restatement of the stage name.

    the actual quiz, project, and activity for that day from the
    source — never generic "Quiz"/"Project." Use the literal name

    specific source fact is a quality defect, not a safe default.

    was populated from source), "Partial — <name what's missing>", or
    "None" (no usable source material for this day at all).
  - Flags: use only the REVIEW FLAG VOCABULARY defined in the Master
    System Prompt section above; leave blank only when every cell in
    the row is Complete with no REVIEW NEEDED/REQUIRES_ID_JUDGMENT/
    CONFLICTING_SOURCES condition present.
  Use "REVIEW NEEDED — no source available" ONLY when the source
  genuinely lacks that detail for that specific cell — never as a
  substitute for looking harder at material that IS present elsewhere
  in the retrieved source.

A day with no retrieved source STILL gets its own row, with its cells set
to "REVIEW NEEDED — no source available" and the Flags cell set to
MISSING_SOURCE. Do NOT drop or merge days just because their detail is
missing.
