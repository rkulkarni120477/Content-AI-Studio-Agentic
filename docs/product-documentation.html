1. Product Overview

Content AI Studio is an enterprise eLearning content generation platform. Authors create instructional content through an AI-assisted pipeline: define style → design course (CDD) → blueprint modules → generate blocks → edit → approve → publish → export to LMS.

Backend FastAPI + SQLAlchemy + PostgreSQL

Frontend React 18 + Vite + Redux Toolkit

AI OpenAI + AWS Bedrock (Claude)

Jobs Thread pool (generation) + Celery/Redis (plagiarism)

Legacy Streamlit UI still in promptops_app/ (optional, port 8501)

10. Local Development Setup

Prerequisites

  • Python 3.11+ (use py on Windows)
  • Node.js 18+
  • PostgreSQL running locally
  • Redis (for Celery plagiarism tasks)
# 1. Environment
cp .env.example .env
cp frontend/.env.example frontend/.env
# Set JWT_SECRET_KEY, DATABASE_URL, API keys

# 2. Python backend
py -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install markdown   # for IMSCC HTML export

# 3. Start API (terminal 1)
py -m uvicorn app.main:app --reload --port 8000
# Docs: http://localhost:8000/docs

# 4. Celery worker (terminal 2) — plagiarism scans
celery -A promptops_app.celery_app worker --loglevel=info --concurrency=2

# 5. Frontend (terminal 3)
cd frontend
npm install
npm run dev
# App: http://localhost:3000

# 6. Seed dev data (optional)
py scripts/seed_db.py
# Login: admin / admin123

Full guide also in project_execution.md.
